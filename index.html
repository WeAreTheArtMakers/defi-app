From a raw log to a finding you can check

Each step leaves evidence behind. Nothing reaches a report unless the step before it can be reproduced.

  1. Ingest

    Logs are read by block range for each network, with the RPC and range recorded for every run.

  2. Decode

    Swap, Sync and Transfer events are decoded per venue: Uniswap v2, v3 and v4, Solidly-style pools and PancakeSwap.

  3. Gate

    A run is published only if coverage, decoding and uniqueness checks pass. Gaps are listed, never hidden.

  4. Detect

    Volume, swap-count and liquidity shifts are measured against a frozen baseline, per token and pool.

  5. Explain

    Every finding ships with its method, the alternative explanations and the SQL that reproduces it.
